## Git Workflow
- Branch model: GitFlow inherited from the global Project Brain conventions.
- Default work base: `develop`.
- Default PR target: `develop`.
- Protected branches: `main` and `develop`.
- Branches: `feature/<issue>-slug`, `fix/<issue>-slug`, `refactor/<issue>-slug`, `chore/<issue>-slug`, `docs/<issue>-slug`, `test/<issue>-slug`, `release/<version-or-date>`, `hotfix/<issue>-slug`.
- Commit format: `type(scope): short description`.

## Code Conventions
- TypeScript-first where applicable.
- Avoid `any` unless justified.
- Keep modules cohesive.

## Team Memory
- Project Brain Markdown is the shared source of truth.
- Cavemem may be used locally for personal/session memory.
- Durable facts from Cavemem must be promoted into Project Brain.
